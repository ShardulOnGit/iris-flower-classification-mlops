Developer Code Snippets

Copy ready-to-run code to call the prediction API in your application.

cURL Request 
curl -X POST "https://iris-flower-classification-mlops.onrender.com/predict" \
     -H "Content-Type: application/json" \
     -d '{
       "sepal_length": 5.1,
       "sepal_width": 3.5,
       "petal_length": 1.4,
       "petal_width": 0.2
     }'
Python (requests) 
import requests

url = "https://iris-flower-classification-mlops.onrender.com/predict"
payload = {
    "sepal_length": 5.1,
    "sepal_width": 3.5,
    "petal_length": 1.4,
    "petal_width": 0.2
}

response = requests.post(url, json=payload)
data = response.json()

print(f"Predicted Species: {data['predicted_species']}")
print(f"Confidence: {data['confidence']:.2%}")
JavaScript (Fetch) 
const response = await fetch("https://iris-flower-classification-mlops.onrender.com/predict", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    sepal_length: 5.1,
    sepal_width: 3.5,
    petal_length: 1.4,
    petal_width: 0.2
  })
});

const result = await response.json();
console.log(`Species: ${result.predicted_species} (${(result.confidence * 100).toFixed(1)}%)`);
